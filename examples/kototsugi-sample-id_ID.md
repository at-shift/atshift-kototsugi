## Yang dapat Anda coba dengan KOTOTSUGI

Konten ini membantu Anda memeriksa **pemformatan Markdown** dan hasil konversinya menjadi blok WordPress.

- Judul dan paragraf
- Teks tebal, tautan, dan `kode sebaris`
- Daftar berpoin dan bernomor
- Tabel, kutipan, dan blok kode

### Alur konversi

1. Periksa Markdown di sebelah kiri.
2. Periksa pratinjau di sebelah kanan.
3. Periksa metode penyisipan pada “Tinjau sebelum menerapkan”.
4. Sisipkan artikel sebagai blok WordPress.

> [!NOTE]
> Menyisipkan konten ini tidak menyimpan pos saat ini secara otomatis.

| Sumber | Hasil di WordPress |
| --- | --- |
| Judul | Blok judul |
| Daftar berpoin | Blok daftar |
| Tabel | Blok tabel |

Konten yang dikonversi dengan `KOTOTSUGI` tetap dapat diedit di editor blok setelah disisipkan.

```text
Konten Markdown -> Peninjauan -> Blok WordPress
```
