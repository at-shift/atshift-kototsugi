## KOTOTSUGIで試せること

この原稿は、**Markdownの見た目**とWordPressブロックへの変換を確認するためのサンプルです。

- 見出しと段落
- 太字、リンク、インラインコード
- 箇条書きと番号付きリスト
- 表、引用、コードブロック

### 変換の流れ

1. 左側でMarkdownを確認します。
2. 右側のプレビューを確認します。
3. 「反映前の確認」で反映方法を確認します。
4. WordPressブロックとして挿入します。

> [!NOTE]
> この原稿を挿入しても、現在の投稿は自動保存されません。

| 項目 | 変換後 |
| --- | --- |
| 見出し | 見出しブロック |
| 箇条書き | リストブロック |
| 表 | テーブルブロック |

`KOTOTSUGI`で変換した本文は、挿入後もブロックエディターで編集できます。

```text
Markdown原稿 -> 確認 -> WordPressブロック
```
