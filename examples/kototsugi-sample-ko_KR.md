## KOTOTSUGI로 확인할 수 있는 내용

이 콘텐츠에서 **Markdown 서식**과 WordPress 블록으로 변환된 결과를 함께 확인할 수 있습니다.

- 제목과 문단
- 굵은 글씨, 링크, `인라인 코드`
- 글머리 기호 목록과 번호 목록
- 표, 인용문, 코드 블록

### 변환 과정

1. 왼쪽의 Markdown을 확인합니다.
2. 오른쪽의 미리보기를 확인합니다.
3. “적용 전 검토”에서 삽입 방법을 확인합니다.
4. 글을 WordPress 블록으로 삽입합니다.

> [!NOTE]
> 이 콘텐츠를 삽입해도 현재 글은 자동으로 저장되지 않습니다.

| 원본 | WordPress 변환 결과 |
| --- | --- |
| 제목 | 제목 블록 |
| 글머리 기호 목록 | 목록 블록 |
| 표 | 표 블록 |

`KOTOTSUGI`로 변환한 콘텐츠는 삽입 후에도 블록 편집기에서 계속 편집할 수 있습니다.

```text
Markdown 콘텐츠 -> 검토 -> WordPress 블록
```
