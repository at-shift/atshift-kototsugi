## Qué puedes probar con KOTOTSUGI

Este contenido permite revisar el **formato Markdown** y su conversión a bloques de WordPress.

- Encabezados y párrafos
- Texto en negrita, enlaces y `código en línea`
- Listas con viñetas y numeradas
- Tablas, citas y bloques de código

### Flujo de conversión

1. Revisa el Markdown de la izquierda.
2. Revisa la vista previa de la derecha.
3. Comprueba el método de inserción en «Revisar antes de aplicar».
4. Inserta el artículo como bloques de WordPress.

> [!NOTE]
> Insertar este contenido no guarda automáticamente la entrada actual.

| Origen | Resultado en WordPress |
| --- | --- |
| Encabezado | Bloque de encabezado |
| Lista con viñetas | Bloque de lista |
| Tabla | Bloque de tabla |

El contenido convertido con `KOTOTSUGI` sigue siendo editable en el editor de bloques después de insertarlo.

```text
Contenido Markdown -> Revisión -> Bloques de WordPress
```
