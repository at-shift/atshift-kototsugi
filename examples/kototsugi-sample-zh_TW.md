## 可以使用 KOTOTSUGI 嘗試的內容

此內容可用來檢查 **Markdown 格式**及其轉換為 WordPress 區塊後的效果。

- 標題與段落
- 粗體文字、連結與`行內程式碼`
- 項目符號清單與編號清單
- 表格、引言與程式碼區塊

### 轉換流程

1. 檢查左側的 Markdown。
2. 檢查右側的預覽。
3. 在「套用前檢查」中確認插入方式。
4. 將文章以 WordPress 區塊插入。

> [!NOTE]
> 插入此內容不會自動儲存目前的文章。

| 原始內容 | WordPress 轉換結果 |
| --- | --- |
| 標題 | 標題區塊 |
| 項目符號清單 | 清單區塊 |
| 表格 | 表格區塊 |

使用 `KOTOTSUGI` 轉換的內容在插入後仍可於區塊編輯器中編輯。

```text
Markdown 內容 -> 檢查 -> WordPress 區塊
```
