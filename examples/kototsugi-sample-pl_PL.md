## Co możesz wypróbować z KOTOTSUGI

Ta treść pozwala sprawdzić **formatowanie Markdown** i jego konwersję na bloki WordPress.

- Nagłówki i akapity
- Pogrubiony tekst, odnośniki i `kod w tekście`
- Listy punktowane i numerowane
- Tabele, cytaty i bloki kodu

### Przebieg konwersji

1. Sprawdź Markdown po lewej stronie.
2. Sprawdź podgląd po prawej stronie.
3. Sprawdź metodę wstawiania w sekcji „Sprawdź przed zastosowaniem”.
4. Wstaw artykuł jako bloki WordPress.

> [!NOTE]
> Wstawienie tej treści nie zapisuje automatycznie bieżącego wpisu.

| Źródło | Wynik w WordPress |
| --- | --- |
| Nagłówek | Blok nagłówka |
| Lista punktowana | Blok listy |
| Tabela | Blok tabeli |

Treść przekonwertowana za pomocą `KOTOTSUGI` pozostaje edytowalna w edytorze blokowym po wstawieniu.

```text
Treść Markdown -> Sprawdzenie -> Bloki WordPress
```
