## 可以使用 KOTOTSUGI 尝试的内容

此内容可用于检查 **Markdown 格式**及其转换为 WordPress 区块后的效果。

- 标题和段落
- 粗体文字、链接和`行内代码`
- 无序列表和有序列表
- 表格、引用和代码区块

### 转换流程

1. 检查左侧的 Markdown。
2. 检查右侧的预览。
3. 在“应用前检查”中确认插入方式。
4. 将文章作为 WordPress 区块插入。

> [!NOTE]
> 插入此内容不会自动保存当前文章。

| 原始内容 | WordPress 转换结果 |
| --- | --- |
| 标题 | 标题区块 |
| 无序列表 | 列表区块 |
| 表格 | 表格区块 |

使用 `KOTOTSUGI` 转换的内容在插入后仍可在区块编辑器中编辑。

```text
Markdown 内容 -> 检查 -> WordPress 区块
```
