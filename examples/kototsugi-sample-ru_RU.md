## Что можно проверить с помощью KOTOTSUGI

Этот материал позволяет проверить **форматирование Markdown** и его преобразование в блоки WordPress.

- Заголовки и абзацы
- Полужирный текст, ссылки и `встроенный код`
- Маркированные и нумерованные списки
- Таблицы, цитаты и блоки кода

### Процесс преобразования

1. Проверьте Markdown слева.
2. Проверьте предварительный просмотр справа.
3. Проверьте способ вставки в разделе «Проверить перед применением».
4. Вставьте статью как блоки WordPress.

> [!NOTE]
> Вставка этого материала не сохраняет текущую запись автоматически.

| Исходный элемент | Результат в WordPress |
| --- | --- |
| Заголовок | Блок заголовка |
| Маркированный список | Блок списка |
| Таблица | Блок таблицы |

Материал, преобразованный с помощью `KOTOTSUGI`, остается доступным для редактирования в редакторе блоков после вставки.

```text
Материал Markdown -> Проверка -> Блоки WordPress
```
