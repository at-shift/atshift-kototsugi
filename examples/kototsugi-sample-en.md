## What you can try with KOTOTSUGI

This source lets you review **Markdown formatting** and its conversion into WordPress blocks.

- Headings and paragraphs
- Bold text, links, and `inline code`
- Unordered and ordered lists
- Tables, quotes, and code blocks

### Conversion workflow

1. Review the Markdown on the left.
2. Review the preview on the right.
3. Check the insertion method under "Review before applying."
4. Insert the article as WordPress blocks.

> [!NOTE]
> Inserting this source does not save the current post automatically.

| Source | WordPress result |
| --- | --- |
| Heading | Heading block |
| Bullet list | List block |
| Table | Table block |

Content converted with `KOTOTSUGI` remains editable in the block editor after insertion.

```text
Markdown source -> Review -> WordPress blocks
```
